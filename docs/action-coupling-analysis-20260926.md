# ショットと無効ボムペナルティの関係

## 結論

同時に確率が下がる場面・更新は実在する。ただし「ボムの罰がショットを
一貫して抑制している」とまでは今回の履歴から言えない。
プレイ中の即時変化では、直前報酬を観測として与えている影響が確認できた。
学習時は行動全体に共通の報酬・advantageを使うため、出力間の干渉はあり得るが、
その寄与を確定するには報酬を除いた対照更新などが必要。

## 調べた範囲

- 新dual-gridモデル：完了した40プレイ、40個の更新後チェックポイント。
- 旧focusedモデル：381回中15プレイの履歴を抽出し、13チェックポイントを評価。
- 固定入力：新モデルの記録済み1プレイから27判断おきに選んだ65場面。
- 同じ場面と他の報酬入力を維持し、`previous_rewards.invalid_bomb`だけを
  0と−7/30（1判断の空撃ちペナルティ）に切り替えて比較。
- 稼働中の学習、モデル、報酬係数は変更していない。

固定場面は1プレイに由来するため全場面の代表とは限らない。特に旧モデルに
与えた場面は新モデルのプレイ由来であり、旧モデルの訪問分布ではない。
未完了プレイは除外。分析中も学習は継続したので「最新」は分析対象の更新40を指す。

## 固定場面の確率推移

空撃ちペナルティの観測入力を0に固定した比較（他の成分は場面ごとの記録値）。

| 新モデル更新数 | ショット | ボム |
|---|---:|---:|
| 1 | 50.97% | 50.65% |
| 10 | 46.29% | 38.22% |
| 20 | 49.33% | 26.40% |
| 30 | 55.66% | 30.61% |
| 40 | 59.39% | 23.86% |

39回の更新差分中、同時低下は12回。ボム低下のみを条件とすると24回中12回。
差分のPearson相関は約−0.050で、一貫した同方向変化は認められない。
これは有意差検定でも独立標本の因果推定でもない。
例えば更新6→7はショット−2.83ポイント、ボム−5.89ポイントと両方低下した。
一方、全期間ではショットは上昇し、ボムは低下した。

## 空撃ちペナルティ「入力」だけを変えた比較

| 保存モデル | ショットの差 | ボムの差 |
|---|---:|---:|
| 新・更新20 | −2.88ポイント | ＋0.38ポイント |
| 新・更新34 | −1.41ポイント | −3.31ポイント |
| 新・更新40 | −1.20ポイント | −3.86ポイント |
| 旧・更新350 | −6.74ポイント | −3.39ポイント |
| 旧・更新381 | ＋2.10ポイント | −0.49ポイント |

更新40ではショット59.39%→58.19%、ボム23.86%→19.99%。重みを全く更新せず、
直前の罰の入力を変えただけで両方下がった。旧モデルにも両方下がる例があるが、
最後の旧モデルではショットが上がるため、常に起こる現象ではない。

実プレイ履歴の「罰の次の判断」の変化は敵・弾・自機等の状態変化も混ざる。
旧381回目では空撃ちの次の判断のショット変化は平均−5.42ポイントだったが、
上記の固定場面試験では反対符号になる。この差は状態分布等の影響を示すもので、
履歴の時間的な同時発生だけで原因を決められない。

## 実装から分かること

`live_learning.py`はプレイ中に重みを更新せず、ゲームオーバー後にPPO更新する。
表示する確率は操作前観測から計算し、その行の報酬は操作後に計算する。
従って、同じ行の「罰と確率」をその罰への即時反応と解釈してはいけない。
次の判断には直前の報酬成分が`previous_rewards`として入る。

SB3のMultiCategoricalDistributionは方向・ショット・低速・ボムの対数確率を
合計し、PPOはその組み合わせに共通のadvantageを適用する。別々の確率出力でも
「無効ボムの罰はボムの勾配だけに流れる」構造ではない。
ただし罰があるだけで全出力が必ず抑制されるわけではなく、advantageの符号、
選択されたON/OFF、他の報酬、サンプル平均や共有層の更新にも依存する。
参考：[PPO公式解説](https://spinningup.openai.com/en/latest/algorithms/ppo.html)。

優先する追加実験は、罰そのものは報酬に残しつつ、直前の無効ボム罰を観測入力から
外した対照試験。入力を外すだけで因果が確定するわけではなく、同一条件の学習比較が
必要。出力番号の入れ替えだけで改善を期待する根拠はない。

データ：`artifacts/action-coupling/analysis.json`、`old-fixed-scenes.json`。
主解析スクリプト：`scripts/analyze_action_coupling.py`。
