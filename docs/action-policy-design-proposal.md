# 操作別判断層の検討（未実装）

記録日：2026-09-26。[改善履歴](model-learning-history.md)に戻る。

## 検討の背景

ボムを押さないように学ぶことが、共有ネットワークを介してショットも押さない判断へ
波及するのでは、というユーザーの問題提起。出力番号の隣接ではなく、共有パラメータの
更新による干渉が論点。[履歴分析](action-coupling-analysis-20260926.md)では同時低下の例を
確認したが、その原因を共有層の更新と特定できていない。直前報酬入力への反応は別の現象。

## 確認済みのユーザーの意向

- 移動と低速は密接に関係する操作として扱いたい。
- ショットは押し続ける場面が多いが、常時ONには固定しない。
  押す・離すを含む操作内容はAIが学習して実施する。
- ボムは普段控え、必要時に使う操作。移動と共通する空間認識を利用する意味はあるが、
  操作の特徴は異なる。

## 構成候補（実装指示・採用決定ではない）

共通の局所／全体グリッド認識から、次の専用判断層に分岐する。

| 判断系統 | 学ぶ内容 |
|---|---|
| 移動＋低速 | 方向と移動速度の組み合わせ |
| ショット | 押す・離す |
| ボム | 空間状況・パワー・発動中状態等を踏まえた発動選択 |

移動と低速を一つの結合した行動分布にするか、中間層だけ共有して出力を分けるかは未決定。
分岐の層数・幅、共有層への勾配の扱い、既存重みの移行方法も未決定。
現在は操作判断の中間層を共有し、最後の確率出力を分ける構成のまま。

## 比較すべき点

共有認識を残せば、専用判断層を設けても共有層経由の干渉は残る。
ネットワークを分けても、組み合わせ全体に共通のPPO報酬を使うことによる影響は別途残る。
「ボムの罰をボムだけに割り当てる」変更は今回の構成案に自動的には含まれない。

まず保存モデルのコピーでボムの判断だけを更新し、同一観測のショット確率への影響を測る。
共有層を固定した対照と比較すれば、共有パラメータ経由の影響を切り分けやすい。
この実験は未実施。構造変更を評価する場合も、報酬・観測条件を揃えて比較する。
ショット常時ON案はユーザーの意向により採用しない。
