# 操作確率の逆転を分離する検証

2026-10-01。実機への変更なし。小型CNNの既存v4対照モデル（seed 7/17/27、16384判断学習済み）をCPU上に読み込み、各512判断を収集した。

## 方法

死亡した判断と直前3判断から、最初のミニバッチ分割で正規化Advantageが負になる14場面（うち死亡判断3）を抽出。各場面について、同一の更新前重みから独立に1回だけ更新した。通常の64件ミニバッチのAdvantageを固定し、単独条件でも再正規化しない。

比較は単独経験のSGD、履歴なしAdam、保存モデルの履歴ありAdam、および64件混合の履歴なし・ありAdam、さらにエントロピー項を加えた条件。測定対象は移動方向と速度の組み合わせの選択確率。価値側は独立しているためこの検証では更新しない。勾配クリップは通常と同じ0.5。

各ミニバッチを順次更新した結果ではなく、すべて同じ学習開始時の重みに戻した反実仮想比較である。過去の監査で起きた全更新の逆転件数をそのまま再現する実験ではない。単独と混合は平均化の係数も違うので、変化量の大小を純粋な干渉の強さと解釈しない。

## 結果

| 条件 | 確率が増えた場面 / 14 | うち死亡判断 / 3 |
|---|---:|---:|
| 単独SGD | 0 | 0 |
| 単独Adam・履歴なし | 0 | 0 |
| 単独Adam・履歴あり | 1 | 1 |
| 64件Adam・履歴なし | 6 | 0 |
| 64件Adam・履歴あり | 5 | 2 |
| 64件Adam・履歴あり＋エントロピー | 5 | 2 |

64件混合では、履歴なしで下がり履歴ありで上がる場面が2件。エントロピー追加で増減の符号が変わる場面は0件だった。各反実仮想比較の終了後、全パラメータが元の重みに一致することをassertで確認した。

## 解釈と限界

この標本では単独の学習信号は操作確率を意図した方向へ動かせる。ほかの経験との混合、およびAdamの履歴は、それぞれ逆転を生じさせ得る。履歴ありの方が全体の逆転件数は少ないため、Adamの履歴が常に悪いという結果ではない。エントロピーは今回の符号逆転の主要因とは見えない。

死亡直前の操作がすべて回避不能・危険だったとは限らない。本実験は負のAdvantageが選択確率に届くかを調べたもので、負のAdvantageの正しさや安全行動との区別は検証していない。14場面は選択された少数標本であり、ゲーム全体の逆転率や性能低迷への寄与率には換算できない。

改善候補はAdamの一次モーメント係数を小さくする比較。ただし履歴リセットの本番採用はしない。採用判断には複数seedで通常条件との一からの学習比較、完走・生存時間と同じ場面での確率変化の両方が必要。混合の問題は学習率を下げるだけでは符号が直るとは限らない。
