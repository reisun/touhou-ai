# Adamの履歴係数を弱める比較

2026-10-01。小型CNN v4のシミュレーター検証。実機の設定・学習には変更しない。

通常のAdam betas=(0.9,0.999)に対し、候補は(0.5,0.999)。一次モーメントの係数beta1だけを下げ、学習率、二次モーメント、報酬、モデル構造、PPO設定を維持する。操作側・価値側の両方に適用しており、操作側のみの効果は切り分けていない。学習途中の履歴を切り替えず、一から学習する。

3初期値7/17/27、各16384判断。対照は同じv4設定・学習量のcritic-normalization-20260930/controlを再利用。候補の初期パラメータと乱数状態が対照ビルダーと完全一致することを確認。対照の設定辞書・判断数も実行時assertで照合。

各モデルで共通96弾幕を確率選択・最大確率選択・開始観測固定の最大確率選択で評価する。この96弾幕は既存の診断セットであり、未知の最終テストではない。死亡罰だけの短い回避課題で、実機フル報酬の長期性能は測らない。

実装: touhou_ai/adam_memory.py。実行: scripts/compare_width_credit.py adam05 SEED。結果保存先: artifacts/width-credit-20260930/adam05。

前回の14場面の因果診断と今回の一からの学習比較は異なる実験。今回の性能差だけでは、操作確率の逆転率が減ったことを改善原因と断定しない。

## 結果：採用しない

| 指標（3初期値平均） | 通常beta1=0.9 | 候補beta1=0.5 |
|---|---:|---:|
| 確率選択の完走率 | 28.47% | 18.75% |
| 平均生存時間（上限10秒） | 7.992秒 | 7.223秒 |
| 最大確率選択の完走率 | 35.07% | 26.39% |
| 最終8収集区間の価値予測RMSE | 0.07188 | 0.06790 |
| 同 explained variance | 0.4121 | -0.2321 |

確率選択のseed別結果（7/17/27）は通常27.08/20.83/37.50%、候補27.08/25.00/4.17%。1同等・1改善・1悪化で、特にseed27の低下が大きい。最大確率選択は候補32.29/6.25/40.63%。3モデルとも全96件で、通常観測と開始観測固定の成功可否・終了フレームが一致した。場面に応じて観測を利用する性能の改善は確認できない。

モデル保存再読み込み後の全重み一致、Adam betas一致、全パラメータ有限値を確認。評価は3モデル×96弾幕×3モード=864件終了。

平均RMSEはわずかに小さいが、学習軌跡・ターゲット分布自体が違うため価値予測が改善したとは解釈しない。explained varianceは3初期値とも対照より低い。

履歴による局所的な逆転が存在することと、履歴を弱めると全体の性能が上がることは別だった。beta1=0.5を操作・価値両側へ適用する案は採用しない。ほかの係数や操作側だけの変更まで否定する結果ではないが、今回追加で探索はしていない。実機設定への変更なし。
