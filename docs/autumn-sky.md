# 秋符「オータムスカイ」再現診断

2026-09-28。Normal、1面ボス秋穣子、最初のスペルカード。
実機学習とは独立したシミュレーター。実機設定・報酬・モデルは変更していない。

## 根拠

所有ゲームの `artifacts/progress-ecl-20260927/stage01.txt` の BossCard1。
ECLテキスト SHA256: 46d6739b5308ac53dc5e6c71c5121102700b323e681185d458ae8ba1f6806c8e。
Normal は diffI で38方向、etAim=3の非自機狙い円形弾。
4組152発を同時発射し、120F間隔で射手0..3と4..7を交互に使う。
全組の初期速度2px/F。各組は60Fの減速後に指定角度へ相対方向転換を3回行い、
最後の転換後は1.2px/F。中間の -999 は元の速度を維持する指定。
色変化は衝突形状を変更しない。

ピン留め実行ファイルの実行中コードを読み取り専用で照合した:
- 0x406974: etAim=3は初期角 + index*2π/38。
- 0x406f64: 方向変化パラメーターの設定、速度センチネル。
- 0x407780: 60Fで速度を線形減速し、相対角を加算して速度を復帰。
- 0x406c3d: 弾種別3の衝突幅はテーブル0x4741ecで4px。自機半径1pxとのAABB半幅3px。
- 0x406c53: フラグ4は出現アニメーション割込み8、半速移動と初期位置-velocity*4。
- 0x406160: 画面外消去はx±192、y−64..448にスプライト半幅/半高を加える。
  通常16×14、出現中30×30（bullet.anm Sprite70/214）。
所有bullet.anmをローカルに抽出し、Script102の割込み8から15Fで通常状態へ移る命令を確認。
公開解析ソース https://github.com/N0zoM1z0/th10 の BulletManager/BulletRuntime/BulletTransform も参照。
実機コードと照合した関数以外を完全一致保証としては使用しない。

## 再現の範囲と限界

- 最初の発射を0Fとした600F（10秒）、5斉射を検証。スペル開始演出150Fと全45秒の耐久は対象外。
- フィールド384×448、2F/判断、自機速度4.5/低速2、斜め正規化、ショット・ボム禁止。
- ボス初期(0,128)。moveRand(60,4,2)を参照した方向選択・減速移動を実装。
- 実機の乱数列は再現せず、NumPyの独立したシードを使う。学習seed7、評価は1000..1023。
- 出現アニメーションの境界1F、敵移動の補間/制限は実機トレース未照合。
  弾の出現15Fでモデル化している。フレーム単位の完全再現ではない。
- 衝突は従来シミュレーターと同様0.25F刻みのAABB。実機の1F更新と結果が異なる可能性がある。
- ボス本体の接触判定、撃破/時間切れ、画面外に別途存在する敵は未実装。回避課題であり取得率ではない。
- グリッドは既存の局所192pxと全画面384×448。局所窓の外に出ただけでは弾を削除しない。
- 数値入力は最大760発全てを固定スロットの位置・速度・存在フラグで扱う（3805入力）。
  従来181入力のチェックポイントとは互換性がない。入力規模とモデル容量も変わるため、
  この比較だけで入力形式の優劣は決めない。未来の転換予定/乱数/正解行動は入力しない。

## 検証方法

各モデルを初期化し、死亡-60のみ、PPO lr1e-4、epochs3、gamma.9995、lambda.95、
rollout512、batch64、targetKL.02、entropy.01。数値MLP/小型CNNともactor/critic分離。
0判断と16384判断時に同じ24種の未学習シードで確率選択と最大確率選択を評価。
乱数操作列は各エピソード独立。平均生存フレームと10秒生存率を記録。
検証の停止条件は環境の600Fを使用し、従来の80判断打切りは流用しない。
これは1学習seedの予備診断。3報酬の比較は含めず、まず新しい弾幕での死亡罰条件を基準化する。

実行: `.venv/Scripts/python.exe -m scripts.train_autumn_sky`
テスト: `.venv/Scripts/python.exe -m unittest tests.test_autumn_sky`

予備実行 autumn-sky-20260928-185826 は上端消去条件を修正する前のため途中停止し、比較結果には使用しない。
