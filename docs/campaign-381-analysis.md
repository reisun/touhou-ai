# 旧・個別弾モデル381回の分析

対象：`live-learning-20260926-131801-321bd8`。
構成：`th10-focused-bullets-v1`、報酬v9。
完了した381回・642,665判断（操作時間約5.95時間）、約14.4GBの記録を集計。
停止時の未完了 `episode-382.jsonl` は比較から除外した。

各回の行数・被弾数・報酬内訳の合計は保存済み結果と一致し、使用した
方策の更新番号の不一致もなかった。新モデルの学習・設定は変更していない。

これは毎回更新される方策の学習過程の分析。第N回は原則として更新N−1の
方策を使用しており、保存済み最終モデル381を固定した再評価ではない。
また、さらに前の122回モデルとは入力構造と低パワー報酬が違うため、
そのモデルとの単純比較から構造変更の効果を断定することはできない。

## 解釈

### 生存と攻撃には改善があるが、攻略には届いていない

平均生存は約21%、初被弾までの平均は約33%、毎秒ダメージは約31%改善。
初被弾の中央値も改善しており、平均だけが外れ値で伸びたわけではない。
ただしボムや無敵時間もあるため、初被弾時間だけで精密回避が上達したと
断言できない。全381回で3機を失い、面移行は0回だった。

最長は第356回の97.13秒、初被弾54.10秒。良いプレイが出ても再現は不安定。
50回移動平均の生存最高区間は266～315回の62.59秒で、最後50回の59.80秒を
上回った。一方、最後31回は63.15秒・初被弾23.31秒で、終盤の改善もある。
「完全に学ばなくなった」より、上下しながら限定的に改善した、と評価する。

### 報酬改善の大部分は無効ボム入力の削減

| 報酬項目／プレイ | 初期50回 | 最後50回 | 差 |
| --- | ---: | ---: | ---: |
| ダメージ | +16.03 | +25.50 | +9.47 |
| 撃破 | +7.93 | +8.47 | +0.54 |
| 被弾 | −45.00 | −45.00 | 0 |
| パワー増減 | −31.67 | −29.45 | +2.22 |
| 低パワー維持 | −33.79 | −39.96 | −6.17 |
| 無効ボム入力 | −40.20 | −9.89 | +30.31 |
| 面クリア | 0 | 0 | 0 |

合計改善36.37のうち、30.31、約83%が無効ボム減点の減少に相当する。
これは報酬内訳の算術的な寄与であり、行動変化の因果的な分解ではない。
無効ボムの選択率は11.68%→2.37%。実際のボム発動回数はほぼ同じだった。
最後50回でも、発動不能・非発動中にボム確率90%以上となる判断は13回あった。

### 高パワーの活用とショットには課題が残る

最後50回の平均Powerは0.757、Power4以上はゼロ。高火力を保った攻略の経験が
ほぼない。低パワー維持の減点は、長く生存する分増える場面があり、報酬だけで
回避能力を比較すると読み違える。意図的な自滅を示す証拠ではない。

ショット選択率が37.61%へ下がる一方で攻撃効率は上がっており、単純な
「撃たなくなったから弱くなった」とは言えない。ただし撃つと有利な場面でも
射撃を止めていないか、状態別に調べる価値がある。下部にいる割合の増加と
攻撃効率上昇は同時に観測されたが、その因果関係は今回の集計では不明。

### 学習更新幅が次の検討点

初期50回→最後50回で、PPOの近似KLは0.0399→0.1026、clip fractionは
31.88%→50.42%。更新によって行動分布が変わる幅が増えている。
学習率0.0003、10 epochsは固定で、target_klは未設定。
価値予測のexplained varianceは0.887→0.911で、数値発散を示してはいないが、
価値予測が合うことと回避・攻略が上達することは別である。

今後、新グリッドの結果を見た後に別実験として、更新回数・学習率の低減や
target_klによる停止を比較する価値がある。近似KLの値だけで停滞の原因が
過大更新だと断定はできない。SB3自体も、クリッピングだけでは大きな更新を
防げない場合のためにtarget_klを用意している。
