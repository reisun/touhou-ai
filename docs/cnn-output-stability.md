# 小型CNNの出力方式と初期値間安定性の追試

2026-09-29。前回3seedで見えた18択の分散低下を、新規7seed（37,47,57,67,77,87,97）で確認する。
各seedで独立9+2と結合18を一から16384判断学習。採用済みCNN・操作/価値別勾配上限・死亡罰-60。
観測、報酬、更新設定は変更しない。実機未変更。

主評価は新規7組の確率選択での10秒完走率の初期値間標準偏差。
前回3組は発見に使ったため、合計10組での集計は補助評価として分ける。
各モデル192弾幕（seed5000..5191、操作乱数19000..19191）で評価する。
最初96と追加96のパネルも別集計。前回モデルの最初96は保存評価を再利用し、後半だけ追加評価。
標準偏差比18/(9+2)、平均差、生存秒、低成績割合（完走率10%未満）を報告する。
両出力に同じseed・評価ケースの再標本化を適用する二軸bootstrapで95%区間を推定。
192回を独立した学習192回とは扱わず、学習の反復数はあくまで7（補助10）とする。

固定終了: 予定した全モデル・全評価を完了し、有利な途中結果による打切りはしない。
安定性を採用根拠とする条件: 新規7組の標準偏差比の95%上限<1、かつ平均完走率差の95%下限>-2ポイント。
満たさない場合は証拠不十分として現行設定を維持する。小標本の区間推定であり証明とは扱わない。
対象は16384判断時点の初期値間安定性。学習途中の上下動や実機・他弾幕への安定性とは別。

## 最終結果

標準偏差比（18 / 9+2）: 0.547。二軸bootstrap95%区間: 0.216〜1.831。
平均完走率差（18−9+2）: -6.25ポイント。95%区間: -13.62〜+0.07ポイント。

この区間は7組という小標本からの近似。学習seedと評価ケースの二軸を対応させて20000回再標本化した。
1未満なら標準偏差縮小、1超なら拡大。平均が低下して低い成績へ揃うケースは別に評価する。
