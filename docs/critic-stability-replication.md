# 価値側最後のTanh除去：安定性の追試

2026-09-29、予定した全比較を完了。**安定性向上は確認できず、Tanh除去は標準設定へ採用しない。**
実行前に7つの追加初期値と判定基準を固定した比較。
小型CNN、独立9＋2出力、死亡罰のみ、SeparateClipPPO、16,384判断を維持。
数値入力・結合18出力は比較対象にしない。実機学習には変更を加えない。

## 元の3初期値・全10初期値との関係

元の3初期値を192弾幕へ拡張すると、標準偏差は7.59→4.55ポイントと縮小傾向が残った。
ただし平均完走率は14.41→14.93%で、改善幅は約0.52ポイント。

全10初期値の集計では平均17.86→18.02%、標準偏差8.91→8.10ポイント。
標準偏差比0.909、95%区間0.565〜1.921で、全体でも安定性向上は確認できない。
最低成績8.33→7.81%、完走率10%未満は2/10→2/10。

最初の3初期値では有望に見えたが、その強い安定化を追加7初期値へ一般化できなかった、という結論。
価値側の飽和を緩和した事実とは分け、回避性能・安定性を理由とした標準採用は引き続き見送る。
モデル・評価データ・比較図は保存し、実機設定は変更していない。

## 設計

主評価は追加初期値37/47/57/67/77/87/97の7組。
元のTanhありモデルは以前の別実験で作成済みの同条件対照を再利用する。
これらの初期値はTanh除去の比較では追加分であり、成績によって初期値を選別しない。
Tanh除去モデルはすべて初期化から学習する。

元の3初期値7/17/27は発見に使った標本なので、追加7種類の主評価と分ける。
10組全体と元の3組の集計も補助的に示す。
全20モデルを192評価弾幕（環境seed5000〜5191、操作乱数19000〜19191）で比較する。
初期96弾幕と追加96弾幕の結果も分けて確認する。
評価弾幕は学習には使用しないが、過去の診断・モデル比較で使用済みのセットである。

## 事前の判定基準

主指標は、確率選択の完走率についての学習初期値間の標本標準偏差。
Tanh除去後/元の標準偏差比を計算し、対応する学習初期値と共通評価弾幕を再標本化するbootstrapを20,000回行う。
95%区間の上限が1未満なら、この追試の基準でばらつき減少を確認したと扱う。

平均差の95%区間の下限が−2パーセントポイントより上であることも確認する。
低い成績に揃っただけの「安定」を避けるため、最低値、中央値、完走率10%未満の初期値数も確認する。
上記2基準と下側の成績を合わせて採用可否を考える。
途中の結果が都合よく見えても打ち切らず、選んだ7組をすべて完了する。

対象は16,384判断時点の初期値間の安定性であり、学習途中の上下動や実機全体の安定性とは別。
標準偏差の区間推定は7初期値では幅が大きくなり得る。区間が1をまたぐ場合、安定性向上が確定したとは言わない。
