# 価値側128→64の比較

ユーザー依頼：逆方向の小型化として価値側最後の隠れ層を64にし、128・256の比較に加える。操作側の構成も説明する。

## 条件

小型CNN v4、死亡罰−1、移動9＋速度切替。価値側の後段は256→128→価値1から256→64→価値1へ変更。操作側256→128と各操作出力は維持。正規化・Advantage変更は併用しない。3初期値7/17/27、各16,384判断、推論1・更新4スレッド。固定96弾幕で確率選択・最大確率・開始観測固定最大確率を比較する。128対照と256結果は前回の同条件試験を再利用し、設定JSONと判断数の一致を照合。

未学習の128モデルから、事前に固定した先頭64ユニットの初期重みを使用。最終headは対応する64結合を残し、元と同じL2ノルムへ尺度調整する。83個の飽和ユニットを選んで削除する実験ではなく、学習開始前からの構成比較。初期actor出力・torch RNGは完全一致するが、初期価値予測を一般に維持できない点は256の中立拡張と異なる。パラメーターは16,512減。層縮小・最終headノルム・optimizer参照・保存再読込一致をテスト。

## 操作側の出力

価値側と別の特徴抽出器を持ち、後段256→128の各隠れ層にTanhを使用。最後の128特徴から線形出力15個を作り、移動9・ショット2・低速切替2・ボム2の各グループを確率化する。移動は8方向＋静止。128は操作の種類数ではない。
実機はこの4グループで操作し、ボムは別途12F周期の意思決定スケジュールを使用。回避用シミュレーターではショット・ボムを無効にし、移動と速度切替を使う。今回の幅変更は価値側のみで、操作側の出力構成は変更しない。

## 限界

短期・3初期値・既存診断弾幕の探索的比較。実機フル報酬の高飽和状態で学習した結果ではない。大きさによる差と初期値の影響を完全には分離できず、16,384判断以降の伸びも未測定。初期値間のばらつきだけで安定性向上を断定しない。

再現：scripts/compare_width_credit.py width64 <seed>。集計：scripts/summarize_width_credit.py。成果物：artifacts/width-credit-20260930/width64。

64のseed7/17/27の確率選択は27.08/22.92/28.13%（128比で1同値・1改善・1悪化）、最大確率は40.63/40.63/10.42%。全3モデルで観測固定でも各96評価の成功可否と終了フレームが通常観測と一致し、観測活用改善は確認できない。

共通44観測の価値側最後のTanh飽和は64も0%。終盤8rolloutのRMSE平均は64:0.0803、128:0.0719。説明分散は64:0.186、128:0.412。説明分散は1初期値で改善・2悪化。異なる軌跡・ブートストラップ目標での指標なので、共通真値に対する精度比較ではない。

初期値間の確率選択完走率の標準偏差は64:2.76ポイント、128:8.42ポイントだが、3初期値の短期試験であり安定性向上とは断定しない。今回の初期化・学習量では、64化で平均性能の改善は得られず、標準採用しない。幅の大小だけが主因とする根拠は得られていないが、長期学習での効果を否定する結果ではない。
