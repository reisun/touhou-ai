# 短期危険度の操作入力への直接追加

## 比較条件（2026-09-29実行）

目的は、観測由来の危険情報を用意すれば死亡罰だけで有利な操作を学べるかの切り分け。
数値相対入力は従来PPO、CNNは採用済みの操作/価値別勾配上限を使用する。
それ以外は configs/autumn-learning-baseline.json を維持する。
操作出力は移動9通りと速度2通りの独立分布。ショット・ボム無効。

変更は、操作側の最終128次元潜在へ18個の危険指標を連結してaction_netへ渡すことだけ。
元の重みと初期操作確率を保持し、追加係数はゼロ初期化。価値側には追加入力を渡さない。
補助損失や危険操作の強制禁止は行わない。全モデルを一から学習する。
危険指標18個は出力の18択化を意味しない。

危険指標は現在見えている弾位置・速度から、各移動×速度で2F移動後14F停止するときの
衝突を等速近似する。未来の発射や軌道変化は参照しない。
そのため完全な安全判定でも、複数操作を続けた場合の被弾確率でもない。

各モデル3初期値（7,17,27）、各16384判断、秋符オータムスカイの最初600F。
基準は前回の同条件3初期値の保存評価。96弾幕seedと操作乱数を揃える。
確率選択、最大確率選択、観測固定の両選択、危険入力のみゼロの確率選択を評価。
別108場面では通常/危険入力ゼロ/危険入力入れ替えで近似危険操作への確率質量を診断する。
このプローブは設計判断に使ってきたため、未使用の最終汎化評価とは扱わない。

単一初期値や局所危険指標の改善だけでは採用せず、初期値間の安定性、完走率と生存時間、
入力を除いた対照との差を確認する。実機学習の設定・プロセスには変更しない。

実行: scripts/compare_direct_risk.py
結果: artifacts/autumn-direct-risk-20260928/{relative,cnn}/
実装・保存再開・初期重み一致・入力経路など6テスト成功。

## 結果

完了。両入力とも未採用。

### 数値相対入力（3初期値完了）

確率選択の平均完走率12.15→7.29%、平均生存6.838→6.444秒。
seed7:25.00→5.21%、seed17:7.29→7.29%、seed27:4.17→9.38%。
危険入力をゼロにした同じ保存モデルは平均8.68%、6.505秒で、直接入力の利点なし。
最大確率選択は15.63→27.78%と上昇し、観測固定10.76%より高い。
ただし危険入力だけを外すと29.17%で、改善は元の観測を使っても維持される。
追加情報が訓練軌跡へ影響した可能性は残るが、推論でその情報を利用する利益は確認できない。
確率選択と最大確率選択を混同せず、今回の追加方式は数値入力の基準へ採用しない。
危険場面108個で近似危険操作への確率質量は、通常25.85%、入力ゼロ26.09%、入替26.01%。
局所指標の改善幅は約0.24ポイントで、完走改善へ結び付いていない。

### 解釈上の範囲

入力ゼロ対照は同じ学習済みモデルの推論時だけを変える。
その結果が同等でも、追加係数が学習途中の軌跡や元のネットワークの更新へ影響した可能性は否定しない。
観測固定対照は全入力を初期観測に固定するので、移動傾向だけで得られる成績の目安になる。
現在の比較は16384判断という同じ予算内の改善を調べたもので、十分長い学習での限界を示さない。
追加危険情報は計算で作った特徴量であり、CNN自体が危険を読み取れるようになったことも意味しない。
補助入力の数は18だが、操作は引き続き方向9と速度2の独立分布である。
