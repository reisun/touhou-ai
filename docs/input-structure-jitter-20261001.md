# 入力・モデル構造による方向の揺れの独立検証

2026-10-01。操作選択のヒステリシス・往復減点の別検証とは独立。実機学習、既存モデル、報酬、共通設定を変更していない。

## 実機モデルを使用

固定モデルは live-learning-20261001-190603-3fbec1/real-episode-14.zip（540更新）。実機のSeparateClipPPOをそのまま読み込み、LiveActionGridContractで入力を生成。観測空間の一致をassert。小型CNNの重みを再初期化しない。シミュレーターは弾のみで、射撃とボムを無効にし、速度切り替えと2Fごとの確率選択は維持した。ボム周期はframe%12、前報酬も入力する。

実機との残る差は敵・アイテム・レーザー・射撃報酬等がないこと、自機速度raw等の簡略化、合成弾幕であること。実機の全プレイを再現したものではない。実機学習の初期化・optimizerには一切触れていない。

## 実際の操作を進める比較

診断と別の弾幕seed6000〜6031、初期y=160/400各16、各条件同じ操作乱数23000〜23031。1つの保存モデルに対する再学習なしのスクリーニング。全128試行完了。

入力EMA：局所グリッドのみ現在と過去を0.5ずつ混合。
特徴EMA：actor側局所CNNの128次元出力のみ現在と過去を0.5ずつ混合。
空間平滑化：actor側局所CNNの3個のstride2畳み込みの直前に3x3平均（replicate padding）を追加。
EMAは初期観測で初期化し各episodeでリセット。全体グリッド・短期衝突予測・価値側・操作抽選規則・報酬は維持。

## 結論と次候補

実機の学習済みモデルと入力を用いると最大候補の揺れを再現できた。特徴の時間平均では最大候補変更が約16.2%、実移動反転が約4.4%減ったが、回避性能改善は確認できず本番採用しない。空間平滑化・入力平均も即時適用では採用しない。

単純平均は現在の情報を弱めるため、次に学習する構造候補は「現在の局所特徴をそのまま残し、前回の特徴/差分を別経路で追加する」もの。反応を一律に鈍らせず、時間的な変化をモデルが使い分ける意図。ただしこの構造の再学習は今回実施していない。新経路をゼロ初期化しactor/criticを分離、episodeごとに状態リセットし、PPO収集・更新の履歴整合を満たす必要がある。単純に推論だけstateを足して学習する実装は不可。
