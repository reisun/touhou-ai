# 往復減点の実機採用（2026-10-01）

ユーザー承認により②の往復減点を採用し、フル操作の実機学習を新規初期化する。
①のヒステリシス操作選択は採用しない。移動9方向・低速切替・射撃・ボムは
既存の確率的方針と操作周期を維持する。小型CNN・独立した操作/価値特徴処理・
SeparateClipPPO・学習率等は現行設定を維持。

## 報酬 v19

- 6判断（12F）の実測移動量の合計が1px以上。
- 正味変位が総移動距離の25%以下（75%以上を相殺）。
- 隣接する移動の間で120度を超える反転が2回以上。微小移動は反転に数えない。
- 条件成立時に−0.1。再判定まで6判断の間隔を置く。
- 被弾・復帰・面移行・欠落した2Fサンプル・不連続な座標では履歴を破棄する。
- 元の射撃・進行・被弾報酬は維持。Power減少報酬は無効のまま。
- 往復減点はPPOのスカラー報酬に加える。既存の直前報酬4入力は形を維持し、
  jitterを追加入力しない（シミュレータ比較と同様）。

判定は6個の移動ベクトルだけで行い、グリッド再計算や判断ごとのファイルI/Oは
追加しない。OBS2に往復減点を表示し、各ゲームの結果へ回数と合計減点を保存する。
必要な細かな切り返しも減点され得るため、完走・進行・被弾と併せて効果を判断する。

根拠は `jitter-penalty-sweep-20261001.md`。−0.1で反転頻度約22%減、
厳しい開始位置の10秒課題の完走率71.9%→81.3%。実機の長期効果はこれから検証する。
