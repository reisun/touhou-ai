# 採用済み設定での独立9+2対結合18の再比較

2026-09-29。数値入力（相対座標）と小型CNNの両方で比較する。
数値は従来PPOの共通勾配上限、CNNは採用済みの操作側・価値側別上限。
基準config: configs/autumn-learning-baseline.json (autumn-baseline-v2)。
危険度入力、危険予測補助損失、未採用の報酬変更は使用しない。

変更は操作分布のみ。基準は移動9×速度2の独立分布、比較は18組の単一カテゴリ分布。
移動9には停止を含むので18方向ではない。ショット・ボムは無効、速度切替は可能。
両方式の最大エントロピーはlog(18)。係数0.01を維持する。
共有する観測処理・操作MLP・価値側の初期重みは同じseedで一致する。
出力層はサイズが異なり、初期乱数の消費も完全には一致しないため3初期値で比較する。

各seed7/17/27、各16384判断、死亡罰-60のみ、秋符オータムスカイ冒頭600F。
独立側は採用済み設定で学習済みの同seed保存評価を再利用する。
参照: artifacts/autumn-separate-clip-20260928/holdout.json の relative/baseline と cnn/separate。
結合側は今回一から学習。以前の結合CNN比較は1seed・共通勾配上限だった。

評価は各96弾幕seed5000..5095、操作乱数19000..19095。
結合分布を方向の周辺分布→選択方向での速度条件付き分布へ分解してサンプルし、
独立側と同じu0/u2を利用する。これは結合分布そのものからの厳密なサンプル。
最大確率選択では18組全体の最大を選ぶ。
通常/観測固定、それぞれ確率選択/最大確率選択の4条件。
観測固定時は初期分布をキャッシュし、物理と衝突処理は維持する。

採否は単一初期値や平均完走率だけでなく、初期値間の安定性、生存時間、
観測固定との差を確認して判断する。実機の学習設定は変更しない。

実行: scripts/compare_joint_adopted.py

### 判断

今回の16384判断×3初期値では、数値入力は悪化、CNNは平均で小幅改善するが初期値間で不安定。
18択の優位を採用できるだけの一貫した証拠は得られず、両モデルとも独立9+2を基準として維持する。
18択一般の無効性を意味しない。CNNの候補として結果を保持するが、実機へは反映しない。
分布、CNN別勾配上限との組合せ、保存再開、評価方法を含む7テスト成功。
