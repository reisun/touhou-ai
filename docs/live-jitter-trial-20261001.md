# 揺れを再現した実機モデルでの二案比較

## 出発点と再現確認
実機540更新時点、live-learning-20261001-190603-3fbec1/real-episode-14.zipを固定。実機と同じCandidateFeatures、操作/価値別256→128、LiveActionGridContractを使用し全重みをstrictで一致確認。変更したのは回避課題用の射撃/ボムのマスク。移動9方向、速度2段階、2F判断は維持。
初期16試行で最大方向の変化2470回。以前の最大方向が固定されたシミュレーターモデルとは異なり、揺れを再現した上で比較。

## ① システム側
同じ保存モデル、32弾幕seed5000..5031、操作RNG19000..19031。通常確率選択、移動のみ最大確率、最大方向と前回方向の確率差が0.05/0.15以下なら前回方向を維持するヒステリシス。初手は最大確率。速度は全条件で確率選択のまま。
2Fごとに再判断し、固定時間の操作保持ではない。比較開始時に切り替え幅の引数漏れを発見してシステム評価を停止・修正、結果は全条件を再実行したもののみ。

## ② 報酬側
同じ実機重みから各条件を開始。optimizerは全条件で新規。乱数7/17/27、各8192判断。死亡罰-1の回避課題に、往復1回の追加罰0/-0.001/-0.003を比較。PPOはオフラインv4の512判断収集・64バッチ・3epoch・lr1e-4等に統一。実機は更新しない。
12F（6判断）の移動ベクトルで、道のり1px以上、始終点距離/道のり<=0.25、隣接移動の120度超の反転が2回以上なら往復と判定。12Fクールダウンで同一窓の重複罰を抑制。静止と単発切り返しは対象外。減点なしの先行プロセスは6Fの診断用判定で起動したが罰は0で、その判定は観測・行動・学習に影響しない。非ゼロ罰は全て12F版で起動。
補助罰はPPOの報酬にだけ加え、previous_rewardsの既存hit項目には死亡罰だけを入力（罰の偽装なし）。往復履歴は観測に追加していない。部分観測・帰属の難しさは残る。これは一からの構造学習ではなく、実機重みからの追加学習。

## 課題と限界
既存の1面スペル由来10秒課題。モデルは実機と同じだが、敵/射撃/アイテムなしの弾幕回避物理で、実機の完全再現ではない。標準開始y330で基準完走率96.875%のため、追加評価としてy160を採用。y240の16試行も93.75%と高く、y160の16試行では62.5%だった。難度は基準モデルだけで選定、全案に同じy160・32seedを適用。既存診断seedであり独立最終テストではない。
学習は標準開始位置のみ。追加条件の敵の初回乱数方向は元のresetで生成後に開始yのみ変更。3訓練乱数は共通初期重みで、3個の独立した実機学習ではない。評価乱数も各弾幕1つなので初期比較として扱う。

実装scripts/live_jitter_trial.py、scripts/live_jitter_challenge.py、scripts/summarize_live_jitter.py。結果artifacts/live-jitter-trial-20261001。保存/再読み込み重み一致・有限値を確認。

## 最終結果

①各32弾幕。標準/難条件の完走率と難条件での実移動反転回数。

|方式|標準完走|難条件完走|難条件反転/秒|難条件方向変更/秒|
|---|---:|---:|---:|---:|
|通常確率|96.875%|78.125%|6.83|24.49|
|移動最大確率|96.875%|84.375%|4.04|17.10|
|幅0.05|100%|81.25%|3.60|13.86|
|幅0.15|100%|93.75%|2.37|7.94|

幅0.15は難条件で通常比反転65.3%減、方向変更67.6%減。最大確率のみより完走3件増(27→30/32)。幅0.05は最大確率より1件悪い。少数の共通32弾幕・単一保存モデルの結果で、一般化や実機性能向上は未確認。幅0.15を追加確認の有望候補とするが実機未反映。

12Fの往復候補窓率も標準9.39→10.65/11.28%、難条件9.20→9.54/9.67%で減らず。報酬罰の今回の強度・8192判断では「震えを抑える」を達成せず、採用しない。難条件の成績向上はあるが、往復を減らした結果とは解釈できない。強度・学習量・部分観測などをさらに切り分けない限り理由は未確定。
