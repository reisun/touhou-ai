## CPU高速化の補足

Ryzen 7 3700X（8コア16スレッド）で、従来はPyTorchの計算を1スレッドに固定していた。
dual-grid化後の待ち時間削減のため、モデル更新時のみ8スレッドへ切替え、終了時に1へ戻す。
報酬、観測、batch size 64、10 epochsは変更していない。

`live-learning-20260926-201451-940156/real-episode-14.zip`（25,151判断・累計15更新）
を引き継いで`live-learning-20260926-204340-262e15`を開始。
初回の1,743判断に対する更新は31.172秒で、保存・再読込も通過した。
このrunは累計34更新・55,062判断まで進み、GPU採用時に最新モデルを引き継いだ。

従来の約47〜69秒（直近6回平均約56秒）はプレイ記録末尾から保存までの推定区間で、
純粋な更新時間ではない。同じデータ量でもないため、31.172秒との単純な倍率比較はしない。
固定データを使った後の比較は[DirectML検証](directml-benchmark-20260926.md)を参照。
