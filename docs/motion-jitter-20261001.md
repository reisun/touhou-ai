# 最大候補の揺れと往復指標

## 実験
既存小型CNN v4対照モデルseed7/17/27（各16384判断学習済み）、弾幕seed5000〜5095。確率選択と最大確率選択各288試行、計576試行。方向の最大候補、1位2位差、選択操作、実移動ベクトルを2Fごとに記録。全試行で既存評価の成功可否・終了フレームが一致した。再学習・報酬変更・実機操作なし。

## ①結果
両方式の全試行で、各試行中の最大確率の移動方向は変化0回。確率選択では方向変更23.356回/秒、120度を超える実移動反転6.698回/秒、最大候補以外の選択62.337%。最大確率選択は方向変更・反転とも0。
完走率は確率28.472%、最大確率35.069%。ただし最大確率は一定方向を選び続けており、観測に応じた精密回避の成功を示さない。

別途、既存の実機contexts.jsonlを読み取った時点の標本では25,553観測、同一episodeかつ間隔0.3秒未満の25,508組、合計2658.814秒。最大候補の変化17,535回、実選択方向の変化21,663回。最大候補変化時の1位2位差の中央値0.101059。約0.1秒間隔の間引き観測であり、2Fごとの全変化数ではない。これは確率操作中の観測であり、最大確率だけで実機を走らせた比較ではない。実機でも最大候補が変化しないという推論は不可。
実機の標本元はartifacts/hit-windows-20261001/contexts.jsonl（採取継続中の時点集計）。シミュレーターと実機では学習条件・モデルが異なる。

## ②指標と結果
往復度=1-|移動ベクトルの総和|/移動距離総和。6/12/24F窓、道のり1px以上、往復度0.75以上、隣接ベクトル間の反転（内積が長さの積の-0.5未満）が2回以上を候補とした。静止は除外。診断窓は重複あり、まだ減点に使用しない。

|窓|完走82試行の候補窓率平均|失敗206試行の候補窓率平均|
|---|---:|---:|
|6F|1.985%|2.139%|
|12F|12.376%|12.297%|
|24F|36.513%|32.303%|

12/24Fでは完走・失敗の全試行で候補が発生。最大確率選択では両群とも0。幾何学的な往復の検出はできるが、有害な震えと必要/無害な修正操作を識別できたとは言えない。完走試行にも無駄な操作はあり得るので、この結果だけで指標や罰が無効とも断定しない。長い窓では成功側の方が高く、現状の指標をそのまま減点として採用する根拠は弱い。

## 判断
確率を絞るだけで実機の震えが解決するとは見込まない。最大候補自体の変化が実機で確認された。一方、既存シミュレーターモデルでは最大候補が固定で、実機の現象を再現できていない。
往復減点は未導入。次は往復が発生した瞬間の弾との位置関係・被弾までの余裕を使い、必要な切り返しと不要な反転を局所的に比較する必要がある。集計の相関は因果を示さない。

実行scripts/audit_motion_jitter.py、集計scripts/summarize_motion_jitter.py。全軌道と集計はartifacts/motion-jitter-20261001。
