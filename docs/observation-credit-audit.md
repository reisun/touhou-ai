実機の学習・設定は変更していない。
実行: python -m scripts.audit_observation_credit / python -m scripts.audit_actor_critic_clipping
出力: artifacts/observation-credit-audit-20260928/{report,trajectory,policy-details,scene-labels,clipping}.json

## 短時間の回避選択

数値独立出力seed7で新規16試行（環境seed2000..2015）を収集。3907判断、13死亡、3完走。
死亡直前8判断と40判断おきの状態から128場面を抽出。全16Fを評価できるframe<=584に限定。
各場面で18操作を分岐し、2F実行、およびその後14F停止した場合を検証。
実際に選択した操作の2F分岐は記録した死亡の有無と一致することをassertした。
一部操作のみ生存する場面における、生存操作への確率配分:

|方式|次の2F（42場面）|2F操作＋14F停止（61場面）|
|---|---:|---:|
|一様選択|83.1%|53.9%|
|数値独立|87.7%|56.0%|
|数値18通り|84.2%|51.5%|
|CNN独立|81.0%|51.6%|
|CNN18通り|83.6%|52.3%|

数値独立は即時回避に多少の傾向があるため「観測を全く使えない」とは言わない。
16Fは停止を含む特定の参照操作であり、最適な連続回避や長期安全の判定ではない。
死亡付近を多く含む場面選択・1seed・数値方針が訪れた状態なので、モデルの総合順位ではない。
現在の位置・速度だけの等速予測は、この2304分岐ではシミュレータの16F判定と100%一致。
旋回を含む全弾幕での一致や、実機との一致を保証しない。

## 価値予測と時間方向の信用割当

収集元の数値独立モデルのみ、自身の方針による将来報酬と比較した。
全3907判断平均の価値予測は-18.10、実現した割引後報酬は-43.56。
試行単位で平均した予測過大分は+27.88、16試行のbootstrap95%区間は+17.40..+38.20。
この評価群では将来の罰を過小評価している。他モデルの同場面の値はoff-policyなので校正評価しない。
GAEの直接の遠方TD誤差の係数(gamma*lambda)^nは1秒先21.1%、2秒先4.47%、5秒先0.0423%。
価値のbootstrap経由で長期効果は伝わるため、これを学習全体の影響率とは呼ばない。
価値予測が弱いと、早い操作に後の被弾を結び付けにくいという仮説に整合する。
過去の左右隙間課題ではlambda=1だけで解決しなかったため、単純な再提案はしない。
診断用GAEは全試行から再計算した値。過去の実際の更新ログではなく、正規化前の符号もPPOの更新方向ではない。

## 分離済みネットワークに残る更新上限の干渉

SB3 PPOはpolicy.parameters()全体を共通のmax_grad_normで制限する。
保存済みAdam状態を保持し、同じ新規512判断・8ミニバッチを使い、各バッチで独立したコピーを1回更新。
ネットワークのactor/criticパラメータが重複しないことをassert。

|量（8バッチ平均）|共通上限|actor/critic別上限|
|---|---:|---:|
|上限処理前actor勾配norm|1.121|1.121|
|上限処理前critic勾配norm|34.910|34.910|
|処理後actor勾配norm|0.01809|0.50000|
|Adam後actorパラメータ変化norm|0.003872|0.023170|

実際の操作側更新量は約5.98倍。更新方向のcosine平均0.339。
actorだけの損失で更新する対照は別上限と同じactor更新になった。
単なる勾配縮小ではなく保存Adam状態を含む実更新にも差が出た。
ただし1モデル・1rolloutの一歩比較であり、更新を大きくすれば生存率が改善するとはまだ言えない。

## 改善候補と比較順

1. **actor/criticの勾配上限を分離**。共有ネットワークの分離とは別の変更。
   報酬・入力・速度切替・独立出力・学習量を固定し、基準と比較する。
   数値相対座標と小型CNN双方で複数seedを使い、sample/greedyに加え観測固定対照、KL、clip率を確認。
   更新が過大ならactorの上限・学習率を調整する。現時点では未採用。
2. **価値予測を改善**。まず上限分離の結果から独立に、死亡罰の数値尺度(-60→-1)か
   critic専用学習率・更新回数を一つずつ比較。尺度変更はadvantage正規化があっても学習全体の完全同値ではない。
   生存率だけでなく、新規on-policy試行の価値校正を確認する。
3. **実観測から作れる危険予測の補助学習**。各操作の短時間衝突危険を位置・速度から算出し、
   観測処理部分に予測させる補助課題をPPOと同時に学習させる候補。
   本番も現在の観測だけで教師信号を作れるので、事前に正解操作を覚えさせる必要はない。
   入力へ18危険値を直接追加する案は別条件にする。旋回・新規発射の予測誤差を測り、断定的な安全ラベルは避ける。
   今回の未来分岐は診断専用で、本番の教師信号には使用しない。

過去の危険低下・脅威通過の報酬追加だけでは十分な反応回避を得ていない。
まず更新処理と価値予測を直す比較を優先し、出力18通りの利点が不要だとは結論しない。
