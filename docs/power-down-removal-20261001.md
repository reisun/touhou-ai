# Power減少報酬の廃止（2026-10-01）

ユーザーの指定により、Power減少を有効な報酬項目から削除した。Power取得報酬の追加と詳細グリッド位置変更は今回の対象外。

- `LiveRewards.ENABLED`、報酬成分の集計、Power減少イベントの生成を削除。
- 廃止した`power_down`イベントを報酬計算に渡した場合は、他の廃止項目と同様に拒否する。
- OBSの報酬項目名・係数表示と、設定ファイルの報酬項目一覧から削除。
- 元の係数が0のため、総報酬と有効な3成分（ショット・進行度・被弾）の計算は変わらない。

## 既存モデルとの互換性

学習を引き継ぐため、報酬契約v18と履歴照合用の重み辞書にある`power_down: 0`は互換情報として保持する。これは有効な報酬項目ではなく、イベント・集計・表示には使わない。

モデルの直前報酬入力は既存の4要素を維持する。廃止項目に対応する旧入力枠には、成分が存在しない場合の既定値0が入り、従来と同一になる。過去の保存モデルや履歴を破壊するための入力次元変更は行わない。
