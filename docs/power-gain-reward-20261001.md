# Power取得報酬（現行v21）

ユーザー指定の表示は **0.1 × 獲得Power**。
実際に取得で増加した内部Power（20 raw = 1.0 Power）に応じて、取得ごとに
`0.1 * amount_raw / 20` を加算する。小P+0.05は+0.005、大P+1.0は+0.1。
Power4.75から大Pで5.0になった場合は+0.025。上限で増加しない場合は0。

2F前後の差分やアイテム消失から取得を推定せず、署名照合済みのゲーム内Power加算
関数0x418930を観測する。呼出元は取得処理の0x41b3db（小P）と0x41b635（大P）に限定。
呼出時のitem type 1/10（+1 raw）、4/11（+20 raw）と引数を照合し、関数終了後の
実増加量・上限処理を確認する。ゲーム内の数値は書き換えない。

これにより同じ2Fにボム消費や被弾があっても、取得分は独立に記録される。
復帰時のPower設定や面初期化は対象外。v21では取得した瞬間がボム中なら加点しない。
取得イベントは消費し、ボム終了後に遅れて加点しない。v20ではボム中も加点していた。
イベントIDで二重計上を防ぎ、面移行の自動ステップ前に取得済みイベントを保持する。
既存のcombatイベント通信へ同梱し、新しい毎判断RPCやファイルI/Oは追加しない。

射撃・進行・被弾・往復減点は維持。直前報酬の4入力は形を維持し、Power取得を
新しい入力次元にはしない。OBS2と各ゲームの取得量・報酬合計に表示/保存する。
