## 現在の条件

- Normal / 霊夢 B、通常起動。ステージ・残機・パワーの書き換えなし。
- ゲーム時間で 2 フレームごとに判断。9 方向・射撃・低速をモデルが選択。
- 確認済みの通常プレイ中の残機減少 1 ごとに、元の被弾ペナルティ -5。
- 元の PPO 学習率、gamma、GAE、clip、entropy、64 batch、10 epochs を使用。
- ゲームオーバー画面で更新。2048 固定長ではなく、実際の試行長のバッファを使用。
  terminal とし bootstrap しない。時間・ステップ上限や途中の異常・停止要求では
  未更新分を破棄し、ゲームオーバーを捏造しない。
- 更新・保存・再読込中は入力をニュートラルに保ち、ゲームオーバー画面と停止した
  ステージフレームを継続検証。終了後に「継続する」を選んで次の試行を開始する。
  同じゲームプロセスを使い、指定回数の完了後もゲームオーバー画面を残す。
- 観測契約 `th10-live-observed-v1` は位置・raw 速度・自機状態と取得可否マスク。
  元の全特徴契約とは別物。敵 HP・加速度・個体 ID を捏造して埋めていません。
- ボムは一択の出力ヘッドで無効化。サンプル後に操作を改変しないため、PPO の
  行動確率と実際の操作に不整合を作りません。

## 段階移行

接続確認用の初回 256 ステップ上限は廃止しました。ゲームオーバーまでの実測分を
更新に使います。新しい実行結果には
`progression` と有効・無効項目を記録します。経過時間だけで検証済みにしません。

未復元の項目は次の実測証拠を取得してから追加します。

| 条件 | 有効化に必要な検証 |
| --- | --- |
| ボム・ボム報酬 | 入力要求と実際の発動の区別、消費・持続状態、発動イベント |
| ダメージ・撃破 | 敵 HP、ボスフェーズ、個体寿命、被弾元。消失を撃破とみなさない |
| 面クリア・残機報酬 | ステージ遷移と本当のクリア、再開・ゲームオーバーとの区別 |
| 全観測特徴 | 継続 ID、加速度、当たり判定、移動境界、レーザー形状 |
| 元の全プロファイル | 上記を含む結合試験、特徴・出力次元変更時のモデル移行検証 |

未検証のレーザー出現、ステージ遷移、不明な残機変化、同期不良では中止します。
現在は 1 面内の限定リハーサルに対応し、全ステージ本運転の準備完了ではありません。

## 開始・再開・停止

```powershell
# 少数回の実機学習。新規モデルから開始。
./scripts/live-learning.ps1 rehearse -Episodes 3 -MaxSteps 1800 -MaxSeconds 600

# 前回の検証済みモデルと optimizer、累積ステップを引き継ぐ。
./scripts/live-learning.ps1 rehearse -ResumeLatest -Episodes 1 -MaxSeconds 180

# 管理中のゲームオーバー画面から継続する。プレイ中のセッションは拒否。
./scripts/live-learning.ps1 rehearse -ResumeLatest -ContinueManaged -Episodes 2

./scripts/live-learning.ps1 status
./scripts/live-learning.ps1 stop
```

`-ResumeCheckpoint` で、このプロジェクトが記録・検証した特定 checkpoint を指定
することも可能です。合成モデルは受け付けません。ハッシュと契約を検証します。
乱数系列・ゲームの途中状態を完全復元するものではありません。

`stop` は管理対象出力の STOP ファイルを作り、次の収集境界で入力解除します。
ゲームは閉じません。更新中の要求は更新完了後に反映され、次のプレイを開始しません。
F8 は入力制御の緊急解除です。通常は事前に起動していたゲームへの接続を拒否します。
`-ContinueManaged` の場合だけ、管理記録の PID・開始時刻とゲームオーバー状態を
検証して接続します。現在の継続対応範囲は Normal / 霊夢 B / 1 面です。
実行予算は新規起動や更新の完了処理を含めた厳密な強制終了期限ではありません。

UI の「ライブ」と「試行履歴」に実機のポリシー・被弾報酬・更新数を表示します。
開始スクリプトは UI を自動表示します。既に開いている場合は `-NoUI` で省略できます。
URL に `?mode=live` を付けるとライブ表示になります。更新中はその状態を明示します。
ポリシー出力は行動直前の観測、フィールドはその行動後の観測です。
ゲーム停止後は最後の観測として表示し、未接続報酬はゼロでなく未取得と表示します。
