# 報酬v15：ボム中の進行度報酬を0にする

進行イベント発生時点の bomb_state が1なら、到達・撃破の進行度報酬を0にする。
通常時は20＋30×残機＋5×Power。ショット報酬は15/1000×(1＋0.5×Power)へ変更。被弾−60は維持。
進行イベントは削除せず、生ログとOBS1の最大到達点に記録する。
ボム中の達成も処理済みにするため、ボム終了後に同じ到達点を再報酬化しない。
操作終了時の状態ではなく、既存ダメージイベントと同じ検証済みアドレスから
イベント発生時点の状態を取得。不明な状態はエラーにする。

観測はth10-dual-grid-v3のまま、報酬契約をth10-rewards-v15へ更新。
旧v14のモデル・記録は保存し、報酬契約の異なるモデルの通常再開は拒否する。

検証：Python全体105件成功（既存1件スキップ）。ショット係数を15へ変更後、
報酬8件・OBS到達点3件を再実行し成功。JSのイベント時点状態保持・不明状態拒否と
OBSグラフ描画テストも成功。ボム報酬0とOBS1到達点記録の両立は統合テストで確認。
実機ではv15・damage=15・resumed_from=nullで新規連続学習のplaying状態を確認。
ボム中の進行イベントが実機で発生する場面の再採取は、この変更時点では未実施。
