# 予測入力と報酬尺度：単独比較

## 事前に固定した条件

ユーザー依頼の①②③を順に検証。小型CNNのみ、採用済みv3を対照とし、変更を積み重ねない。
各条件は初期値7/17/27の3モデル、各16,384判断を初期重みから学習。
ネットワーク初期値・操作乱数は7/17/27。学習環境の初回seedは全条件7に固定し、その後は環境乱数を継続する。
操作により訪れる位置やボスの動きは変わるため、学習軌跡まで同一とはしない。
対照も新規学習し、物理のハッシュ・設定・初期重み一致を確認する。
移動9＋独立速度切替、SeparateClipPPO、元の価値側Tanh、入力の形状とモデル容量を維持。
実機学習と採用済み標準設定には変更を加えない。

1. `urgency`: 2F移動後停止の経路を維持し、予測入力を二値から接触時刻に変更。
   予測範囲内に接触する場合は `1 - 接触時刻 / (予測範囲F + 1)`、接触しない場合は0。
   即時接触は1、予測範囲末端の接触も0より大きく、安全と区別する。
   安全操作間の距離余裕は今回追加しない。これは切迫度という単独変更の検証。
2. `continuous`: 二値を維持し、16F側だけ同じ方向・速度で移動し続ける予測へ変更。
   壁で停止する各区間を連続衝突判定。実際の行動判断は引き続き2Fごと。
3. `scale`: 元の二値・2F移動後停止入力のまま、死亡罰−60を−1へ変更。
   報酬の種類、学習率、entropy係数、value係数等は維持する。
   PPOのadvantage正規化があるため、操作側への学習圧が単純に60分の1となるとは解釈しない。

主評価は96弾幕×3初期値の確率選択による完走率と生存時間。
最大確率選択、初期観測固定の両選択方式、同一場面での入力置換と危険操作への確率、価値側Tanh飽和率も確認。
評価seed5000〜5095は過去にも使用した診断用条件で、未使用の最終汎化試験とは扱わない。
3初期値の探索的比較だけで安定性を確定しない。良い1初期値だけで採用しない。

実装: `touhou_ai/risk_refinements.py`。
学習: `scripts/compare_risk_refinements.py`。
集計: `scripts/report_risk_refinements.py`。
証跡: `artifacts/risk-refinements-20260929/`。

## 事前検査

二値予測の元実装との一致、切迫度を二値化したときの一致、移動継続案の2F側一致、解析可能な接触時刻と経路差、
死亡罰以外の観測・軌跡一致、4条件の初期重み完全一致をテストし、2テスト成功。

## 判断

①は追試候補。平均完走率・生存時間は改善したが2初期値改善・1悪化で、改善幅の区間は0をまたぐ。
初期値27の最大確率選択は通常41.67%に対し観測固定1.04%で、観測が有効だった例が出た。
ただし他の2初期値では最大確率の通常/固定成績が同じ。共通危険場面の操作反応にも一貫した改善はない。

②の今回案は不採用。完走率・生存時間とも悪化し、全3初期値で完走率が低下した。
これは16F継続移動への置き換え単独の結果で、複数経路の併用など別方式の否定ではない。
移動継続予測の物理照合は59場面×18操作で2F不一致1/1,062、16F不一致23/1,062。
将来の変速等は観測にないため完全予測ではない。詳細はcontinuous-fidelity.json。

③が最有力。3初期値とも改善、平均完走率+11.81ポイント、生存時間+0.669秒。
価値側Tanh飽和が解消し、終盤の説明分散・死亡罰で単位を揃えた学習目標誤差も改善した。
ただし通常/観測固定の確率完走率は28.47%/28.12%、最大確率では双方35.07%。
危険場面の入力置換に対する反応も強まっておらず、観測に応じた回避の弱さは残る。
価値学習の改善と回避成績改善は同時に確認したが、前者が後者を生んだ因果関係を単独で証明した比較ではない。

標準設定・実機の学習は今回変更していない。次の優先候補は③の追加初期値・新規評価弾幕での追試。
①と③の併用は未検証なので、単独結果から効果が加算されるとは見なさない。

### 計算と実装の補足

②開始前に予測範囲へ到達不能な弾を保守的な距離上限で除外する最適化を追加。
除外前との予測値完全一致をテスト済み。①の学習は除外なしで実行しており、処理時間を純粋な方式差として比較しない。
報酬縮小以外のPPO係数は維持。advantage正規化等を含むため、③を単純に「死亡を60分の1しか重視しない」とは解釈しない。

## ユーザー判断による③の採用

検証後、③をシミュレーターの小型CNN標準v4へ採用した。死亡罰−1、その他の採用済み構成は維持。
標準factoryとtrain_autumn_baseline.pyのcnn起動で有効。数値入力の旧報酬は変更しない。
採用前v3をautumn-learning-reference-v3.jsonとbuild_spatial_reference_modelに固定し、risk_refinements比較もそちらへ接続。
採用済みモデルと検証時の③の初期重み・環境軌跡・死亡報酬一致、短い学習・保存再開を含む5テスト成功。
稼働中の実機runは死亡罰−60のまま原因調査し、途中の尺度変更や再起動はしていない。
