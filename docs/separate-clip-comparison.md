# 更新上限分離の比較（2026-09-28、完了）

## 変更と固定条件

操作側・価値側のネットワークは従来どおり分離。勾配normの上限0.5を全体共通から両者別々へ変更する。
PPO.trainはSB3 2.7.0から保持し、上限処理呼び出しだけ変更したことをテストで検査。
各16384判断、初期値7/17/27、数値相対座標と小型CNN、速度切替可能・独立出力。
死亡罰-60、他の報酬なし、ショット・ボム無効。学習率0.0001、512判断/rollout、batch64、3epoch、gamma .9995、lambda .95。
全試行は初期化から学習。実機の稼働中モデルは変更しない。

## 検証

数値3seedとCNN seed7の従来モデルは既存の同一条件チェックポイントを使用。
CNN seed17/27は元のrunnerで追加し、変更条件と3seedで対応を取る。
既存24弾幕シードに加え、未使用の環境seed5000..5095・操作乱数19000..19095で各モデルを評価する。
確率選択を主指標に、完走率と生存時間を確認。最大確率選択・初期観測固定を併記する。
複数初期値での改善と新規弾幕での改善を確認し、特定seedのみの改善は採用理由にしない。
観測固定と同等なら反応回避の改善とは呼ばない。数値とCNNは別々に採否を決める。
初期値3つでの比較なので一般的な学習性能の確証とは区別し、採用時もまず実験の基準へ反映する。

実装: touhou_ai/separate_clip_ppo.py
テスト: tests/test_separate_clip_ppo.py（2件成功。数値/CNN双方の独立上限、原版との単一変更を検査）
学習: scripts/compare_separate_clip.py
追試・独立評価: scripts/finish_clip_comparison.py
出力: artifacts/autumn-separate-clip-20260928、artifacts/autumn-clip-baseline-20260928

## 数値モデルの独立評価結果

各学習seedにつき未使用96弾幕、計288試行/方式。確率選択の完走率12.15%→15.63%、平均生存6.838→7.194秒。
seed別の完走率は25.0→8.33%、7.29→19.79%、4.17→18.75%。平均の改善は安定しない。
最大確率選択の完走率15.63%→8.33%。観測固定・確率選択は7.99%→10.76%。
環境seedを対応付けて再標本化した完走率差の95%区間は-2.43..+9.38ポイント。
この区間は学習seed3個を固定した評価弾幕の不確かさのみであり、新しい学習初期値への保証ではない。
数値モデルの標準へは採用しない。実装と結果は比較候補として保持する。

保存・再開テストを追加し計3テスト成功。
独立評価の固定観測モードは推論結果をキャッシュし、不要な再エンコードを省略。
CNNの8試行で従来実装と全結果が一致。frozen_sample 9.06→1.65秒、frozen_greedy 14.99→2.34秒。
評価の数学的条件、実際の通常観測評価、学習条件は変更しない。

## 報酬尺度の単独予備比較

第一候補との相互作用を混ぜないため、双方とも従来の共通上限から死亡罰だけ-60→-1にした。
seed7・各16384判断・元の24弾幕での予備比較。物理・観測・終了条件の一致を確認済み。
数値: 完走率12.5→0%、生存7.34→6.10秒。CNN: 4.17→12.5%、5.85→7.43秒。
CNNは観測固定でも12.5%。1初期値のみであり尺度変更は未採用。候補を一般に無効とは結論しない。
このCNN予備比較は今回採用した上限分離との組み合わせ比較ではない。
出力: artifacts/autumn-reward-scale-20260928、実行: scripts/compare_reward_scale.py。

数値モデルの新規on-policy16試行では全16試行が死亡。
元の-60単位へ戻した価値予測平均-53.60、実現割引報酬-57.17、MAE5.70。
旧モデルの別軌跡では予測-18.10、実現-43.56、MAE33.36だったが、同一状態での比較ではない。
死亡だけとなった評価では実現報酬の標準偏差1.83と小さく、評価平均を答える定数予測のMAEは1.51。
平均への接近は、有利な操作を区別する価値予測の改善の証明ではない。
この尺度変更の予備比較を理由に実機の死亡罰は変えない。
