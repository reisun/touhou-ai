# ショット報酬維持／半減の実機比較

ユーザー依頼：同一保存モデルからショット報酬維持と半減を比較し、Tanh飽和と回避・射撃への影響を確認。

初回は各3ゲームの学習比較。現在の通常学習を次の保存境界で停止し、同一checkpoint（重み・optimizer・乱数）から両条件を開始する。維持は0.25×(1+0.5×Power)/1000HP、半減は0.125×(1+0.5×Power)/1000HP。他の報酬・観測・PPO条件・操作間隔は変更しない。

実機の乱数や弾幕を同一に固定できないので、3ゲームの成績差を因果効果として断定しない。学習中の成績であり、凍結モデルの独立評価ではない。学習判断数も到達時間により異なる。通常プレイの生存時間・初被弾までの時間・最大到達点・非ボム時の実ダメージ・射撃選択率を比較し、総報酬は元係数換算も併記する。

共通の過去ボス観測20件（299/300更新時の採取）に対し、共通開始モデルと各条件1〜3更新後を同一入力で評価。Tanh abs>0.99の割合、場面間の特徴変動・価値予測の幅を比較する。観測セットは小さく、未知場面での一般化性能の証明ではない。

比較条件は専用 `ShotStudyGames` / `ShotRewardScale` で明示し、通常報酬の既定値は変えない。半減checkpointには専用報酬バージョンを付け、通常学習へ無条件に再開できないようにする。両条件のcheckpointを保存し、比較終了後は従来係数側の最終保存モデルから通常学習を再開する。

実行：scripts/run_shot_reward_study.py。解析：scripts/analyze_shot_reward_study.py。結果はartifacts/shot-reward-study-20260930。

## 実測結果（2026-09-30）

共通開始は live-learning-20260930-131411-785dbd/real-episode-90.zip、305更新。維持は live-learning-20260930-201644-dfa245、半減は live-learning-20260930-203318-a4348a。各3ゲーム、308更新まで実施。初期policyハッシュ一致、全保存モデルのハッシュ・再読込・乱数再読込を検証済み。両条件とも通常のゲームオーバーで終了し、異常回復更新は0件。

到達点は維持が2面スペル突破(id15)、2面ボス着、2面中ボス着。半減が2面中ボス着、2面スペル突破(id19)、2面中ボス突破。全ゲーム被弾3回。ゲーム秒数は収集判断数×2F/60で、会話自動送りや最適化時間を含まない。秒間ショットダメージは全プレイ時間を分母とするため、同じボスへの射撃精度を直接比較した値ではない。

結論：半減で価値側の飽和がわずかに低くなる兆候はあるが、短期の3更新では高い飽和を解消していない。回避成績は平均初被弾時間が延びた一方、3ゲーム目は早く被弾し、平均プレイ時間は同程度。射撃選択率は近いが実ダメージは少し低い。これだけでは回避・射撃性能改善や「ショット報酬が飽和の主因」を確定できない。すでに飽和したモデルからの短期継続であり、半減が長期的に無効という結論でもない。

補足：previous_rewardsも入力に含むので、半減条件は学習目標に加えてプレイ中の報酬入力も変わる。飽和診断ではprevious_rewardsを含めた入力を全モデルで同一に固定しており、重み変化を比較している。初期PPO乱数を揃えても実機側の乱数は一致しない。KL停止により実エポック数も異なる。比較は探索的な短期試験で、独立した凍結モデル評価ではない。
