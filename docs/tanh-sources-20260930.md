# Tanh直前の値の分解

2026-09-30。依頼は入力・重み・バイアスのどこで大きな値が生まれるかの診断。実行中の学習・モデルは変更せず、前回比較の共通305更新、維持308更新、半減308更新をCPU1スレッドで解析した。入力は前回と同じ20ボス観測（previous_rewardsを含め固定）。scripts/diagnose_tanh_sources.py、artifacts/tanh-sources-20260930/analysis.jsonが再現用成果物。

## 方法

各Linearをz=xW^T+bで再構成し、forward結果との最大誤差<1e-3を全層で検証（実際は数e-6以下）。Tanh飽和はabs(output)>0.99、直前の絶対値ではatanh(0.99)=2.64665を超える状態。xの20場面平均をmuとし、z=(mu W^T+b)+(x-mu)W^Tに分解。前者を共通成分、後者を場面変動とした。RMSは成分の二乗平均平方根で、寄与率ではない。

バイアス除去・入力半減・平均中心化・重み行ノルム1化は各Linearの出力だけを再計算する診断。前段からの再学習や性能評価ではなく、運用モデルへの処置でもない。特に20場面平均の中心化はこの標本に依存し、LayerNormと同一ではない。

## 前段への追跡

共通モデルの最初の価値Tanh直前はxW RMS5.529、b RMS0.0233、飽和35.88%。その入力特徴RMS1.603、絶対値最大11.375。特徴統合Linearへの枝別加算成分RMSは全体グリッド1.806、自機状態0.405、局所グリッド0.117、ボム時計0.027、衝突予測0.0084、直前報酬0.0055。全体グリッド経路から大きな値が入る。ただしこれらは重要度や回避への有効性ではなく、当該統合層での値の大きさであり、相互の相殺もある。

「報酬入力が直接大きすぎる」はこの標本では支持されない。一方、将来の累積報酬を学習した結果として重み・特徴がこの状態になった可能性は残る。現在の順伝播の分解では、過去の学習でなぜそうなったかの因果関係までは決まらない。

## 解釈と次の候補

この20場面では、全体グリッドを含む特徴の大きさと学習済み重みの組み合わせが、場面共通の大きな値を作り、価値側最後のTanhを同じ端へ押し付けている。半減3更新後も構造はほぼ同じ。次の比較候補は価値側の特徴スケール・中心の正規化、または最後のTanh除去。ただし中心化すれば数値上の飽和が下がることと、価値精度・回避成績が上がることは別で、別々に一からの学習比較が必要。既存のTanh除去検証を参照して設計し、現在の重みに直接適用する根拠にはしない。

20件は近接した過去のボス観測であり、全ステージで83ユニットが固定という主張ではない。通常学習は変更していない。
